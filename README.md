# Fowohodie - Wheelchair Conversion Kit Platform 🦽⚡

A **social impact e-commerce platform** for Fowohodie, a Ghanaian startup creating innovative **wheelchair conversion kits** that transform manual wheelchairs into motorized ones. This platform promotes accessibility and mobility independence across West Africa.

## 🌟 About Fowohodie

**Fowohodie** is a pioneering Ghanaian assistive technology company founded by **Kelvin Acheampong Domfeh**, a mechanical engineer and social entrepreneur. The company designs and manufactures locally-made battery-powered motor systems that can be installed on existing manual wheelchairs, making motorized mobility accessible and affordable for individuals with physical disabilities.

## 📦 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (LTS recommended)
- [Git](https://git-scm.com/)
- npm or yarn package manager

### Installation

1. **Clone the repository**
```bash
git clone <repository-url>
cd fowohodie
```

2. **Install dependencies**
```bash
npm install
```

3. **Start development server**
```bash
npm run dev
```

The application will be available at `http://localhost:5173/`

### Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint for code quality checks
